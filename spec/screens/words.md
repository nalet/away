# 17 Words

The words Away uses for its own things. A page uses each one for the same
thing, and no other word for it. The texts of each screen are in its chapter's
last section.

## 17.1 What things are called

| Word | What it is |
|---|---|
| machine | A computer one reaches through Away. Never host, server, target or endpoint. |
| desktop | A machine's own screen, with everything on it. |
| program | One program of a Windows machine, opened without its desktop. |
| shell | A machine's command line. Never terminal or console. |
| way in | How a machine can be opened: its desktop, its programs, its shell. A machine has one or more. |
| session | One's work on one machine, from opening it until it ends. A machine's programs are one session together. |
| connection | The line a session runs over. A connection can drop and come back while the session goes on. |
| the session's bar | The bar across the top of a session, with what Away offers there. |
| the handle | The small tab at the top edge of a session that opens the bar. |
| group | Machines that an administrator put together, such as finance. Also the groups of people that the identity provider gives; a page says which it means: “a group of machines”, “a group of people”. |
| rule | Says which group of people reaches which machines, and what may pass. |
| role | What someone may do in the administration: an administrator, a reader of the records. |
| favourite | A machine one has marked with the star, to see it first. |
| last used | The machines and programs one opened most recently. |
| kept account | A name with a password or a key that Away keeps for a machine and never shows. People are signed in with it and type nothing. |
| identity | What a machine proves itself with, so that Away knows it is the machine it claims to be. |
| file | Where machines, groups and rules are written. What the files say and Away applies is “in force”. |
| test | Trying a machine as a connection would: reaching it, checking its identity, signing in. |
| record | One entry of what happened: a connection, a sign-in Away made, a change. Never log or audit trail. |
| sign-in service | Where people sign in: the organisation's identity provider. |

## 17.2 What things are said with

| Say | And not | Because |
|---|---|---|
| sign in, sign out | log in, log on, authenticate | one pair of words for Away and for a machine |
| as yourself | single sign-on, pass-through | it says what happens: one is on the machine with one's own account |
| you type a name and a password | enter credentials | the words people have for it |
| leave it running | disconnect | it says what becomes of the desktop |
| sign out of the machine | log off | the same pair as everywhere |
| open, open again | connect, launch, start | a machine is opened, as a file is |
| end | terminate, kill | a session ends |
| couldn't | failed to, unable to | the design system's word for what didn't work |
| a moment ago, 12 min ago | timestamps alone | how long ago is read faster; the exact time is beside it where it matters |

## 17.3 How they are written

- What one presses and what heads a page or a card is in lowercase, in the
  monospace face: `open again`, `machines`, `sign out`.
- What one reads is a sentence in the body face, with a full stop.
- A machine's name, a person's name, a group's name and a file's name keep the
  case they have.
- A key is named as it is on the keyboard, in lowercase with a plus between:
  `ctrl + alt + del`.
- A number that comes from a rule or from the configuration is read from it
  when the page is shown: 30 minutes on one installation is 2 hours on another.
