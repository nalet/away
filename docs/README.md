# Documentation

Away is not built yet, so there is nothing to install and nothing to run. What
exists is its [specification](../spec/README.md): what Away is for, what it has
to do, what it looks like, how it is built and in what order. It is a first
cut, under review.

| To | Read |
|---|---|
| see what Away is for | [the goals](../spec/goals/README.md), or [the goal map](https://nalet.github.io/away/spec/goals/map/) |
| see what it does, and when | [the capabilities](../spec/capabilities/README.md), or [the capability map](https://nalet.github.io/away/spec/capabilities/map/) |
| see what people expect of it, and what the plan makes of that | [the expectations](../spec/capabilities/expectations.md) |
| see what it leaves out | [what is left out](../spec/capabilities/left-out.md) |
| see what it looks like | [the screens](../spec/screens/README.md), or [all screens](https://nalet.github.io/away/spec/screens/all/) on one page |
| see how it is built, and why | [the architecture](../spec/architecture/README.md) and its [decisions](../spec/architecture/decisions/README.md) |
| see which piece of Away carries a capability, and when it is built | [where each capability is carried](../spec/architecture/carried.md) |
| see in what order it is built | [the work packages](../spec/plan/README.md) |
| change any of it | [changing the model](./model.md) |

How to install, set up and run Away is written here with each part that is
built.
