# Documentation

Away is being built, and there is nothing to install or to run yet. What
exists is its [specification](../spec/README.md): what Away is for, what it has
to do, what it looks like, how it is built and in what order. The owner agreed
to it on 14 November 2026, and [the work packages](../spec/plan/README.md) say
how far the build is.

|---|---|

| see what it does, and when | [the capabilities](../spec/capabilities/README.md), or [the capability map](https://nalet.github.io/away/spec/capabilities/map/) |

What is built so far: the program with its three parts, the chart and the
pipelines; Away's own RDP code, proven against real machines; signing in, and
the frame of the pages; the machines and the rules as files, with home
showing each person the machines a rule gives them; and the first sessions: a
Windows desktop and the programs of a Windows machine, of one machine or of a
farm of machines, open in the browser with a name and a password the person
types. Shells and other desktops are not opened yet.
