# Reporting a security hole

Away opens the door to every machine it knows, so a hole in it matters. Please
report one in private, and not as a public issue.

## How

Use GitHub's private reporting for this repository:
<https://github.com/nalet/away/security/advisories/new>

Say what you found, where, and how to see it happen. A report doesn't have to
be complete to be welcome.

## What happens next

| When | What |
|---|---|
| within three working days | an answer that the report arrived and who is looking at it |
| after that | what was found: whether it is a hole, how bad it is, and when a fix is planned |
| with the fix | a release, and an advisory that names what was wrong and thanks whoever reported it, if they want to be named |

Nothing about a report is made public before a fix is released, unless the
reporter and the project agree otherwise.

## What counts

Anything that lets someone reach a machine, a session, a sign-in or a secret
that Away should have kept from them, and anything that lets a machine harm
Away or a person's browser. A hole in a library Away is built from counts when
it can be reached through Away.

Away is being built, and no version is released yet. Reports about the code on
the main branch are welcome all the same.
